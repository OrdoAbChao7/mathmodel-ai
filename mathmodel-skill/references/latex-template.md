# LaTeX Reference

Use XeLaTeX with the CUMCM class/template selected from `vendor/`. Keep the main file short and split chapters into `sections/` or `contents/`. Prefer `amsmath`, `mathtools`, `bm`, `booktabs`, `tabularx`, `graphicx`, `subcaption`, `listings`, `hyperref`, `cleveref`, and a GB/T 7714-compatible bibliography only when the selected template supports them.

Compile repeatedly when references or citations are present. Use vector PDF/SVG figures where practical, consistent units and captions, `\label` immediately after captions/equations, and `\cref` for cross references. Do not hard-code page numbers or use identity information in the body when the current contest notice forbids it.

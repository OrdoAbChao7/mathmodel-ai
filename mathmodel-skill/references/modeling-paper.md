# CUMCM Paper Structure

Recommended order: title and abstract; keywords; problem restatement; assumptions; notation; overall analysis; model construction for each question; solution algorithm; results; sensitivity/robustness; model evaluation; conclusions; references; appendix with reproducible code or derivations.

For each question use the chain: purpose -> data processing -> assumptions -> variables -> equations -> method -> parameter fitting -> result -> interpretation -> validation. Explain why the model answers the question, not merely how an algorithm runs.

The abstract must state the problem, core models, main quantitative results, and conclusions. Avoid vague claims such as “the model is accurate” without an error metric. Keep symbols consistent, define units, and number equations that are referenced later.

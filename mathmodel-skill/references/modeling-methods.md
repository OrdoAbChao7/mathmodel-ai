# Modeling Method Selection

Choose the simplest model that answers the question and can be validated. Common families include regression and time series for prediction, linear/integer/nonlinear programming for allocation, AHP/entropy/TOPSIS for multi-criteria evaluation, ODE/PDE or physical laws for mechanisms, Monte Carlo for uncertainty, clustering/classification for grouping, and genetic algorithm/PSO/simulated annealing only when exact methods are unsuitable.

Every heuristic must state encoding, objective, constraints, initialization, stopping rule, random seed, and comparison baseline. Report sensitivity to key parameters and do not confuse an optimizer's best objective value with real-world validity.

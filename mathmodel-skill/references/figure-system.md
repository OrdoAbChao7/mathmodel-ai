# Figure System

Register figures before citing them. Cover four roles: data understanding, method structure, primary result, and validation. Give each figure a stable ID, project-relative file, source data, generation script, role, caption purpose, body label, supporting result or claim IDs, and color/black-and-white readability decision.

Use axes with units, legible labels, consistent scales, and captions that state what decision the reader should draw. Prefer generated vector graphics where practical; include a table when exact comparison values matter. Use figures to explain evidence, not to decorate pages.

Reject missing files, unregistered figures, duplicate decorative plots, figures with unreadable labels, and a figure count that satisfies a threshold without covering each required role. Regenerate a figure when its data, code, or linked result changes.

# Real-case evaluator oracle

This directory is evaluator/judge-only. The Solver must not read it before candidate freeze or during a locked holdout run.

Keep reference winning papers, known solutions, judge notes, award metadata, detailed evaluation, human failure analysis, and prior generated solutions here. Mount or copy this directory only into the Evaluator/Judge workspace. If a holdout oracle or detailed holdout comparison is exposed and the system is then changed, that case is no longer a valid locked holdout.

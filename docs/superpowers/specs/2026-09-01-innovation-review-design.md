# Innovation Review Design

The formal review registry now includes an independent `innovation` reviewer. This reviewer is not rewarded for selecting a newer algorithm; it must document five questions: the concrete problem need, the counterfactual value of the proposed innovation, its origin in the problem structure, empirical support, and why it is not merely a mechanical model combination.

The assessment must include non-empty evidence references to registered result or validation artifacts. Missing or malformed assessment evidence creates `G8-INNOVATION-001: FAIL`, so a complete list of reviewer types alone cannot make G8 pass. Existing research-mode behavior remains not applicable, and existing review findings still retain their independent critical-finding gate.
